Kritagya Kautilya Portfolio

Files:
- index.html  -> main portfolio page
- style.css   -> design and responsive layout
- script.js   -> mobile menu, active navigation, footer year
- profile.jpg -> your profile photo (already connected in index.html)

How to open in VS Code:
1. Open this folder in VS Code.
2. Open index.html.
3. Right-click index.html and choose "Open with Live Server" if the Live Server extension is installed.
   Or double-click index.html to open it in a browser.

To change the photo later:
- Replace profile.jpg with another JPG/PNG image.
- Keep the filename profile.jpg, OR change src="profile.jpg" in index.html to the new filename.
